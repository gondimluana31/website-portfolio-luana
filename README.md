# website-portfolio-luana

Site de portfólio pessoal, desenvolvido com HTML, CSS e JavaScript puros, seguindo o design criado no Figma.

## Estrutura do projeto

```
website-portfolio-luana/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── images/
    └── fonts/
```

## Como rodar localmente

Basta abrir o `index.html` no navegador, ou usar uma extensão como o Live Server (VS Code) para recarregamento automático.
